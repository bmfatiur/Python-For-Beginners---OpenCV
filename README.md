# Python-For-Beginners---OpenCV

### For Linux (Ubuntu/Debian)
```
python3 -m venv opencvpy
source opencvpy/bin/activate
pip install numpy pandas matplotlib notebook
```
### For Windows
```
python3 -m venv opencvpy
opencvpy\Scripts\activate
pip install numpy pandas matplotlib notebook
```

### For Regular use
```
<!-- Linux -->
source opencvpy/bin/activate
jupyter notebook

<!-- Windows -->
opencvpy\Scripts\activate
jupyter notebook
```
